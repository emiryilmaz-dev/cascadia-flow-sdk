# Cascadia Flow SDK

Lightweight Python SDK and workflow templates for building reliable, AI-powered automation pipelines with **Cascadia Flow Labs**.

## Features

- **Declarative Workflow Graphs**: Chain LLM calls, webhook triggers, and deterministic Python steps in minutes.
- **Built-in Retries & Fallbacks**: Automatic exponential backoff and schema validation for production reliability.
- **Cloud-Native Ready**: Zero heavy runtime dependencies; deploys cleanly to AWS Lambda, Cloud Run, or containers.

pip install cascadia-flow
